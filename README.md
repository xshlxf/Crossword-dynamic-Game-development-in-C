# Crossword-dynamic-Game-development-in-C
This project is a dynamic crossword game developed in the C programming language. It is designed to demonstrate concepts from systems programming such as processes, signals, and threads, creating an interactive command-line experience.
 # Features

- Dynamic generation of crossword puzzle boards
- Command-line interface (CLI) for user interaction
- Use of processes and threads to manage game logic
- Synchronization and communication using signals
  
 # Requirements

- POSIX-compatible operating system (e.g., Linux, macOS)
- C compiler (e.g., gcc)
- Compilation and Execution
